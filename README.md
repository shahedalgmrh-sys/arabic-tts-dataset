# Arabic Audiobook SRT Dataset

مجموعة بيانات من ترجمات نقطيّة (SRT) لكتب صوتية عربية + ملفات الصوت الأصلية بجودة MP3_160K،
مع سكربت بايثون لتحليل جودة الترجمات.

**الإجمالي:** ~49 ساعة صوت، ~78 ألف ترجمة، ~304 ألف كلمة.

## هيكل الملفات

- `*.srt` — النسخة الأصلية (من التعرف على الكلام ASR).
- `*.cleaned.srt` — نسخة منظّفة ومصححة نصيًا (تصلح الأخطاء المختلطة من ASR).
  - لاحظ: لا توجد ملفات MP3 في هذا المستودع بسبب حد GitHub (100MB)؛ حيث بقيت محلية.

## تشغيل السكربت

```bash
python analyze_srt.py [المسار]
```

يفحص كل ملف SRT ويطلع: عدد الترجمات، المدة، التداخلات، الفجوات، سرعة الكلام (WPS/CPS)،
الترجمات القصيرة/الطويلة جدًا، الكتل الفاسدة، والترتيب الزمني.

## ملاحظات الإصلاح الأخير

كتاب القرآن يغيرك المنظّف كان مقطوعًا عند 10 ساعات بالضبط (سقف أداة التنظيف)، فقد استُعيدت الطوابع الزمنية لـ
1,029 ترجمة أخيرة من الملف الأصلي — ونحن نصل إلى 10:52:29 صحيحًا.
